## NourishMap Indonesia

The newest selected project is an interactive public-health data story built with HTML, CSS, JavaScript, D3.js, and TopoJSON. It includes a provincial choropleth, searchable province profiles, rankings, socioeconomic and age inequality lenses, national trends, programme-coverage comparisons, and explicit methodological limitations based on SSGI 2024.

Repository: https://github.com/mohmalikirafli/indonesia-child-nutrition-map

## Local preview

From the project directory, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
http://localhost:8000/cv/
```
