## Recent additions

### Public Health AI Audit Lab

An evidence-grounded benchmark for evaluating AI-generated public-health answers. The project contains six synthetic expert scenarios and a 12-point rubric spanning factual accuracy, epidemiologic and statistical reasoning, evidence integrity, safety and uncertainty, equity, and actionability.

Repository: https://github.com/mohmalikirafli/public-health-ai-audit-lab

### Surabaya SSK Implementation Readiness Dashboard

An interactive bilingual implementation dashboard translating a 166-school SSK assessment into school-level maps, regional summaries, implementation indicators, barriers, filters, and actionable programme priorities.

Repository: https://github.com/mohmalikirafli/surabaya-ssk-readiness  
Live dashboard: https://mohmalikirafli.github.io/surabaya-ssk-readiness/

### NourishMap Indonesia

An interactive public-health data story built with HTML, CSS, JavaScript, D3.js, and TopoJSON. It includes a provincial choropleth, searchable province profiles, rankings, socioeconomic and age inequality lenses, national trends, programme-coverage comparisons, and explicit methodological limitations based on SSGI 2024.

Repository: https://github.com/mohmalikirafli/indonesia-child-nutrition-map  
Live dashboard: https://mohmalikirafli.github.io/indonesia-child-nutrition-map/
